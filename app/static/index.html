Connect your own Gmail

Create a Google Cloud project, enable the Gmail API, and add your account as an OAuth test user. Create a Web application OAuth client with this redirect URI:

http://127.0.0.1:8765/auth/callback

Set GOOGLE_CLIENT_ID and GOOGLE_CLIENT_SECRET in your terminal, then restart the app. The project README has the full steps.
